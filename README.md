# 이세계 용사

브라우저에서 바로 실행 가능한 HTML/CSS/JavaScript 기반 2D 탑다운 방치형 RPG입니다.

## 실행 방법

1. 프로젝트 폴더로 이동합니다.
   - `cd /Users/jynoh/starlight-rpg`
2. 로컬 서버를 실행합니다.
   - `npm start`
3. 브라우저에서 아래 주소로 접속합니다.
   - `http://localhost:8000`

Node.js 24 이상이 필요합니다. `npm start`로 게임과 공유 보스 API를 함께 실행합니다. 파일 직접 열기나 Python 정적 서버로는 공유 보스 기능을 사용할 수 없습니다.

## 주요 기능

- 직업 선택: 전사, 마법사, 궁수
- 자동 이동 및 자동 전투
- 여관 휴식 기능
- 장비 장착, 수리, 인벤토리 관리
- 포션 자동 사용
- 상점 기능
- 주간 서버 공유 월드 보스 시스템
- 자동 저장 및 오프라인 보상

## 저장 위치

브라우저의 `localStorage`에 저장됩니다.

## 구조

- `index.html`: 게임 UI와 화면
- `css/style.css`: 스타일
- `js/data.js`: 데이터 테이블
- `js/state.js`: 상태 및 저장 관리
- `js/main.js`: 게임 로직

## 사용자 제작 이미지

`assets/` 폴더에 PNG 파일을 추가하면 향후 코드에서 해당 이미지를 로드하도록 확장할 수 있습니다.


## 레드드래곤 HP 공유

- 모든 유저가 **같은 Node 서버 주소**로 접속해야 HP가 공유됩니다. 개인 PC마다 따로 서버를 띄우면 별도의 보스가 됩니다.
- 서버가 HP를 관리하며 클라이언트는 1초마다 동기화합니다. 연결이 끊기면 보스 도전이 비활성화되고 자동 재연결합니다.
- HP, 피해 기록, 참여 보상 지급 여부는 `.data/boss.sqlite`에 저장됩니다. 서버 재시작에도 유지됩니다.
- 한국 시간 월요일 00:00에 새 주간 보스가 생성됩니다. 지난 시즌의 늦은 공격은 새 보스에 반영하지 않습니다.
- 피해를 준 참가자는 처치 후 250,000 G를 브라우저 식별자별로 주 1회 받습니다. 관전자에게는 지급하지 않습니다.
- 현재 유저 식별은 브라우저 쿠키입니다. 계정 로그인이나 다른 기기 간 캐릭터 공유는 포함하지 않습니다.
- 현재 캐릭터 능력치는 로컬 저장이며 공격 피해를 클라이언트가 제출합니다. 서버는 수치 범위·공격 빈도·중복 요청을 검증하지만, 공개 경쟁 서비스의 조작 방지에는 서버에서 캐릭터와 전투까지 계산하는 추가 작업이 필요합니다.
- 다른 지역의 유저도 접속하려면 Node 서버를 호스팅하고 HTTPS 주소로 제공해야 합니다. 이번 변경은 로컬 구현이며 외부 배포는 수행하지 않았습니다.

환경 변수: `PORT`(기본 8000), `STARLIGHT_DATA_DIR`(기본 `.data`). 호스팅할 때 이 데이터 폴더를 영속 저장소로 설정하고 서버는 한 인스턴스로 실행합니다.

검증: `npm test`로 게임·보스 저장소 테스트를 실행합니다. `node scripts/check-shared-boss.mjs`는 임시 서버/DB를 만들고 두 독립 유저의 HTTP 공유와 동시 공격을 검증한 뒤 종료합니다.
